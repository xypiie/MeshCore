Region priority

Keep airtime for the repeater operator

A designated scope can protect airtime for maintenance or emergency coordination when routine traffic is heavy.

180 s shared

90 s burst and 90 s paced. Any traffic can use this airtime.

180 s reserved

90 s burst and 90 s paced. Only floods in the preferred scope can use this airtime.

At 10% duty cycle, dutycycle.burst 50 splits 360 s into burst and paced airtime. The 50% region reservation protects half of each quota.

Region priority command reference

Set up and save

set dutycycle 10
set dutycycle.burst 50
region put notfunk
region allowf notfunk
region prio notfunk 50
region save

Verify and run separately

region get notfunk
region prio
flood 3600
flood 3600 notfunk

Replace notfunk with your region. region prio notfunk 0 disables the reserve. Save again to persist it.
